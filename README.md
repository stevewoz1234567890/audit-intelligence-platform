# Audit Intelligence Platform

A professional digital reference library for auditors — standards, frameworks,
risks, controls, procedures and an AI Audit Assistant, in one searchable platform.

**Developed by Dr. Noora AlZaraa**

---

## Running the demo

No installation, no build step, no server required.

Open `index.html` in any modern browser.

---

## Pages

| File | Purpose |
|---|---|
| `index.html` | Homepage — hero, framework tiles, AI assistant, updates, provenance |
| `frameworks.html` | Index of all frameworks, populated and scheduled |
| `framework.html?fw=<id>` | Framework section with its own customized sidebar |
| `record.html?id=<id>` | Full standard detail — all audit content sections |
| `search.html?q=<query>` | Global search across the whole library |
| `assistant.html` | AI Audit Assistant with mandatory source citations |
| `tools.html` | Practical tools — programmes, matrices, checklists, papers |
| `resources.html` | News and alerts, articles, training and CPE |
| `myspace.html` | Bookmarks, recent activity, settings |
| `admin.html` | Admin / CMS — create, edit and delete content records |

## Project structure

```
index.html              entry point
framework.html          per-framework template (driven by ?fw=)
record.html             per-standard template (driven by ?id=)
search.html             global search
assistant.html          AI audit assistant
tools.html              practical tools
resources.html          learning and resources
myspace.html            user area
admin.html              content management

assets/
  app.css               complete design system, light and dark themes
  app.js                shared chrome, search engine, assistant retrieval

data/
  library.js            all content — frameworks, records, tools, updates
```

Every page loads `data/library.js` then `assets/app.js`, then renders itself.
Shared chrome (sidebar, header, footer) is generated by `mount()` so navigation
and the footer credit stay identical across all pages from one definition.

## Content model

Each standard record carries the full audit field structure:

| Field | Contents |
|---|---|
| `requirement` | What the standard obliges |
| `focus` | Audit focus areas |
| `risks` | Risk statements, each rated High / Medium / Low |
| `controls` | Controls, typed Preventive / Detective / Corrective |
| `procedures` | Step-by-step audit procedures |
| `testing` | Testing approach, including recalculation guidance |
| `evidence` | Evidence required to support the conclusion |
| `redFlags` | Indicators warranting investigation |
| `findings` | Common findings in practice |
| `causes` | Typical root causes |
| `impacts` | Risk and impact if unaddressed |
| `recommendations` | Actionable recommendations |
| `references` | Links to the official source |

Provenance fields on every record: `source`, `version`, `effective`, `updated`,
`url`, `tier`.

---

## Content licensing — two tiers

The `tier` field on every framework and record records how content may be held.

**`open`** — openly licensed sources: FATF, Basel/BIS, INTOSAI and public
regulator material. Full text may be held and reproduced.

**`ref`** — copyrighted frameworks: IIA, COSO, ISACA, ACFE, IFRS, PMI, ISO.
Held as a complete structured reference — standard number, title, issuing body,
version, effective date, official link — plus **original** practical audit
guidance written for this platform. Verbatim copyrighted text is never
reproduced. Every record links to the official source so auditors can reach
the authoritative text.

This distinction is shown in the interface, so the basis of every record is
visible to the reader.
